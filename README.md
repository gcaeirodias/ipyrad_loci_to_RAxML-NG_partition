# ipyrad_loci_to_RAxML-NG_partition.sh
Simple shell script to convert the file containing the filtered loci outputted from ipyrad (.loci) to a file containing the DNA partition in phylip format (.phylip) needed to run RAxML-NG with multiple partitions. The script only requires the path to the file.loci and file name desired for the partition file. Usage details inside the script file.
